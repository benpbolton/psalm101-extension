Permissions & Review Notes

Psalm101 Browser Extension · Chrome Web Store Transparency

Single Purpose

Filters explicit and suggestive images and video frames on web pages locally on the user's device before they are displayed.

Permission Justifications

  • storage: Stores the filtering strictness level (0–3), video-filtering toggle, and optional salted SHA-256 parent-lock password hash locally in chrome.storage.local, stores temporary unlock expiry in chrome.storage.session, and reads optional administrator policy overrides from chrome.storage.managed.
  • offscreen: Hosts the local ONNX Runtime Web inference engine (engine.html / engine.js) with WebGPU, WebNN, and WebAssembly support, since Manifest V3 service workers cannot access WebGPU/DOM APIs needed to decode images and run the bundled neural network locally.
  • <all_urls> host permissions: Injects content.js/content.css at document_start so images stay hidden before paint across visited sites, fetches cross-origin image bytes locally when canvas readback is blocked by CORS, calls chrome.tabs.captureVisibleTab strictly when unreadable <canvas>, cross-origin <video>, or unverified CSS background candidates are present on screen, and reads the active tab title/URL only when the user manually clicks Copy under Page Diagnostics.

No Remote Code & CSP

All JavaScript, WebAssembly (vendor/ort-wasm-simd-threaded.asyncify.wasm, MIT), and ONNX model weights (models/accurate.fp16.onnx, fine-tuned from Apache-2.0 Google SigLIP2-B/16) are bundled directly inside the extension package. The 'wasm-unsafe-eval' CSP directive is used strictly to instantiate the bundled ONNX Runtime Web .wasm CPU fallback when WebGPU/WebNN is unavailable. The extension makes zero calls to developer servers, third-party APIs, or localhost services.
