Privacy Policy

Psalm101 Browser Extension · Last updated November 23, 2026

Short version: Psalm101 runs 100% locally inside your browser. No images, video frames, screenshots, URLs, browsing history, analytics, or telemetry are ever sent to any external server.

1. Data Accessed Locally

To perform its single purpose — filtering explicit and suggestive visual content before it is displayed — Psalm101 transiently reads the following data exclusively in local browser memory:

  • Page images and CSS background images: Pixels or image files on web pages you visit are decoded and evaluated locally by the bundled on-device machine learning model (SigLIP2-B/16 running via ONNX Runtime Web).
  • Video frames (when "Filter video" is enabled): Frames sampled from playing <video> elements are classified locally in memory and immediately discarded after display.
  • Visible-tab captures (backstop only): Strictly when a page contains unreadable <canvas>, cross-origin <video>, or unverified CSS background candidates, the extension uses chrome.tabs.captureVisibleTab to crop and classify only those candidate regions locally in memory, then discards the capture immediately.
  • Active tab title and URL (user-initiated diagnostics only): Read only if you manually click Copy under Page Diagnostics in Settings to copy recent local image-check status events to your clipboard.

2. Zero Data Transmission & No Tracking

  • Psalm101 operates completely offline after installation — the ML model weights and ONNX WebAssembly/WebGPU runtime are bundled inside the extension package.
  • The extension never transmits images, video frames, screenshots, URLs, browsing history, or usage analytics to the developer or any third party.
  • The extension makes image fetches only to the same websites you are already visiting when cross-origin browser canvas restrictions prevent reading pixels directly from the page.
  • Psalm101 contains no ads, no trackers, no third-party SDKs, and no remote code execution.

3. Local Storage

Psalm101 stores only minimal configuration locally in chrome.storage.local (and reads optional administrator-configured browser policy from chrome.storage.managed):

  • Selected filtering strictness level (0–3).
  • Whether video filtering is enabled (true/false).
  • An optional parent-lock password stored solely as a salted SHA-256 hash (never in plaintext), plus a temporary unlock timestamp in chrome.storage.session.

Image classification probability scores are cached only in transient volatile RAM (up to 5,000 entries, never written to disk) and cleared when the browser or service worker closes. Images and screenshots are never saved to disk.

4. Chrome Web Store Limited Use Compliance

Psalm101's use of information received from browser APIs adheres strictly to the Chrome Web Store User Data Policy, including the Limited Use requirements. Local visual content is used solely to provide real-time on-device content filtering and is never sold, shared, transferred, or used for advertising, profiling, or creditworthiness.

5. Open Source & Contact

Psalm101 is open-source so anyone can audit its code and privacy guarantees directly at github.com/benpbolton/psalm101-extension. For privacy questions or security reports, please open an issue on the GitHub repository.
