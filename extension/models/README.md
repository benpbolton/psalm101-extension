# Model weights

`accurate.fp16.onnx` (~177 MiB, fine-tuned from Apache-2.0 Google `SigLIP2-B/16 @256`) is hosted on
[GitHub Releases](https://github.com/benpbolton/psalm101-extension/releases) rather than git.

Run `make fetch-assets` from the repository root to download `accurate.fp16.onnx` and the matching
`onnxruntime-web` `.wasm` binary automatically.
